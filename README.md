### 📖 项目简介

**MyEnglishHub** 是一个专为英语学习者打造的轻量级应用。无论你是为了考研、雅思、托福，还是单纯想积累词汇，它都能帮你把枯燥的录入过程变得智能且优雅。

本应用采用**本地化优先**策略，无需复杂数据库配置，即开即用，主打一个干净，便捷的学习体验。

### ✨ 核心功能

####  **单词本 (Vocabulary Bank)**

[√] **精简模式**：仅展示单词，音标和词义，同时带有词义遮挡功能便于您memorize

[√] **完整模式**：单词、音标、英译中、英译英、例句——四重保障，让你对单词的记忆根深蒂固。

[√] **AI 智能填充**：别再手动查词了！无论是单个单词、一张截图、一段话还是一份单词文档，AI 都能为你一键纠错并自动补全所有信息。

####  **资源库 (Resources)**

[x] **资料管理**：支持英语资料上传与分类，让你告别文件夹混乱，温故而知新。

[x] **精选推荐**：为你筛选高质量英语学习资料。

####  **打卡系统 (Daily Check-in)**

[x] **遗忘曲线分析**：可视化展现记忆进度，科学规划复习任务。

[x] **GitHub 热力图**：通过你的录入数据生成专属“贡献图”，看到绿色小方块堆叠起来的那一刻，学习动力爆棚！

####  **灵活设置 (Settings)**

[x] **自定义体验**：支持主题、字体调整等，打造专属于你的学习空间。

[x] **API 配置**：支持多种通用 AI 接口（支持 OpenAI 协议），你可以自由配置自己申请的 API Key，上传无忧。

### 🛠️ 技术方案说明

* **数据存储**：为了保障隐私与轻量化，本项目采用 **浏览器本地存储 (Local Storage)**，不依赖繁琐的后台数据库，即便是断网环境下也能流畅运行。
* **跨平台支持**：无论是在手机还是web，都能提供完美的适配体验。
* **开源承诺**：本项目绝对不是“半拉子工程”，在暑假结束前，我将完成全功能的上线与开源。
